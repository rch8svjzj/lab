# CI/CD Checklist

## Pre-commit
- [ ] Run formatting
- [ ] Lint changed files
- [ ] Run unit tests

## Build
- [ ] Verify build reproducibility
- [ ] Cache dependencies
- [ ] Pin versions

## Test
- [ ] Run integration tests
- [ ] Check test coverage threshold
- [ ] Run security scan

## Deploy
- [ ] Use immutable artifacts
- [ ] Rollback strategy defined
- [ ] Smoke test after deploy

## Monitoring
- [ ] Logs centralized
- [ ] Alerts on key metrics
- [ ] Dashboard updated
